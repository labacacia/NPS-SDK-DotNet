# Security Policy

## Reporting

Use GitHub private vulnerability reporting: https://github.com/labacacia/NPS-SDK-DotNet/security/advisories/new. Do not open a public issue. Include the affected version, reproduction conditions, and impact, with secrets and unrelated data removed.

Only the latest maintained branch and latest pre-release are supported unless maintainers state otherwise.

## Scope

Treat frames, endpoints, certificates, keys, and serialized data as untrusted. Closely review parsing, crypto, identity, network, dependency, and publishing changes.
